# `scaffold.data_gen.static`

Every time-invariant variable `satterc data-gen` knows how to produce, with
the generator that makes it. Add an entry here to give a new model's static
input realistic values; anything absent falls back to [`fallback`](fallback.md).
See [`spec`](spec.md) for what a generator is handed.

::: satterc.scaffold.data_gen.static
